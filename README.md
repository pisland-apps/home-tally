# Home Tally

A private, offline-first web app (PWA) for keeping household records.

- Runs entirely in the browser: no backend, no analytics, no third-party tracking.
- Data is stored locally in the browser (IndexedDB) and protected with a local passcode; the passcode never leaves the device.
- Static files only (`index.html`, `ledger.js`, `sw.js`, `theme-init.js`, `manifest.json`, bundled fonts and PDF viewer).
- Not affiliated with, and does not imitate, any bank, payment service or other company.
